<objective>
Port legacy Django seating allocation logic and Razorpay checkout checkout routines into a unified Next.js/Prisma service set. Build verified API payment checkouts, secure webhook endpoints, and an interactive seating preview panel for organizers.
</objective>

<threat_model>
### Trust Boundaries
- **Razorpay Signature vs Webhook Request**: Webhook request payloads are checked against webhook signature headers to prevent malicious checkout spoofing.
- **HMAC secret in environment**: Private Razorpay credentials are kept server-side and never sent to client-side.

### STRIDE Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Spoofing | Webhook endpoint | mitigate | Verify raw request body with crypto.createHmac using SHA256 against x-razorpay-signature header. |
| T-03-02 | Information Disclosure | Checkout / Payment logs | mitigate | Validate inputs via Zod and isolate payment logs strictly per-authenticated user session. |
| T-03-03 | Tampering | Team registration status | mitigate | Perform database updates (marking payment 'paid' and team 'is_registered = true') atomically in a Prisma transaction. |
</threat_model>

  <read_first>backend/participant/payment_services.py</read_first>
  <action>
    Create helper file `lib/services/razorpay.ts`.
    Implement three functions:
    1. `createRazorpayOrder(amount: number, receipt: string): Promise<any>`
       - Executes Basic Auth HTTP POST request to `https://api.razorpay.com/v1/orders` passing amount in paise (amount * 100), currency "INR", and receipt ID.
       - Returns JSON order object containing the order ID.
    2. `verifySignature(orderId: string, paymentId: string, signature: string): boolean`
       - Verifies frontend returns using HMAC-SHA256 signature check via crypto.createHmac.
       - Uses crypto.timingSafeEqual with buffer length validation.
    3. `verifyWebhookSignature(rawBody: string, signature: string, webhookSecret: string): boolean`
       - Validates webhook payloads by computing HMAC-SHA256 of raw text body against the signature.
       - Uses crypto.timingSafeEqual with buffer length validation.
  </action>
  <verify>tsc --noEmit compiles successfully</verify>
  <acceptance_criteria>
    - lib/services/razorpay.ts contains createRazorpayOrder, verifySignature, and verifyWebhookSignature.
    - Uses timing-safe comparisons for both verification routines.
  </acceptance_criteria>

<task type="auto">
  <name>Task 3: Create API endpoints for payments and webhook verification</name>
  <files>app/api/payment/checkout/route.ts, app/api/payment/verify/route.ts, app/api/payment/webhook/route.ts</files>
  <read_first>prisma/schema.prisma, lib/services/razorpay.ts</read_first>
  <action>
    1. Create `app/api/payment/checkout/route.ts`:
       - Authenticates session using `auth()`.
       - Extracts `teamId` from request POST payload.
       - Queries hackathon fee from the associated team's hackathon database record.
       - Creates a Razorpay order via `createRazorpayOrder`.
       - Logs a new pending payment record in `participant_payment` using Prisma client.
       - Returns the order JSON to frontend client.
    2. Create `app/api/payment/verify/route.ts`:
       - Authenticates session using `auth()`.
       - Extracts checkout details: `paymentId` (database primary key), `razorpay_payment_id`, `razorpay_order_id`, and `razorpay_signature`.
       - Verifies signature using `verifySignature`.
       - Performs database update inside a Prisma `$transaction`: marks payment as "paid" and marks the corresponding team `is_registered = true`.
       - Returns `{ success: true }`.
    3. Create `app/api/payment/webhook/route.ts`:
       - Reads raw text body from webhook request.
       - Extracts signature from header `x-razorpay-signature`.
       - Verifies webhook signature using `verifyWebhookSignature` with `process.env.RAZORPAY_WEBHOOK_SECRET`.
       - Decodes payload. If event is `payment.captured` or `order.paid`:
         - Extracts `razorpay_order_id`, `razorpay_payment_id`, and `razorpay_signature`.
         - Finds matching pending payment record in database.
         - Performs transaction update: marks payment status as "paid" and sets team `is_registered = true`.
       - Returns status 200.
  </action>
  <verify>npm run build succeeds</verify>

    - app/api/payment/verify/route.ts validates signatures and updates team registration state.
    - app/api/payment/webhook/route.ts validates raw request bodies with HMAC checks.
  </acceptance_criteria>
