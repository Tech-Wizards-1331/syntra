<objective>
Implement profile management pages for organizers and participants with strict middleware redirects for incomplete profiles, server-side Cloudinary uploads, and an interactive skills tag editor.
</objective>

<threat_model>
### Trust Boundaries
- **Server Action Validation**: Validate that profile updates are executed by the logged-in user in session.
- **File Upload Filter**: Clean and restrict file uploads to valid images and size bounds before posting to Cloudinary.

### STRIDE Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | Profile Server Actions | mitigate | Check session user ID in save actions to ensure users only modify their own profile data. |
| T-04-02 | Tampering | Logo Upload | mitigate | Verify file buffer type and restrict file sizes to max 5MB before uploading to Cloudinary. |
</threat_model>
