<threat_model>
### Trust Boundaries
- **Auth.js session vs Client browser**: Session JWT stored in HttpOnly, Secure, SameSite=Lax cookies, isolating it from client-side script reads.
- **Server side password processing**: Credentials provider verifies passwords in memory on the server. Passwords are never logged or stored in plain-text.

### STRIDE Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | Login Form / Session | mitigate | NextAuth session cookies are set with HttpOnly, Secure, and SameSite=Lax flags. |
| T-02-02 | Tampering | Session Cookie | mitigate | NextAuth cookies are encrypted and signed out-of-the-box. |
| T-02-03 | Spoofing | Password Verification | mitigate | Use crypto.timingSafeEqual for password buffer comparisons to eliminate timing attack vectors. |
</threat_model>

<task type="auto">
  <name>Task 2: Create Django PBKDF2 &amp; MD5 hashing utility</name>
  <files>lib/auth/django-password.ts</files>
  <read_first>prisma/schema.prisma</read_first>
  <action>
    Create a helper file `lib/auth/django-password.ts`.
    Implement two functions:
    1. `verifyPassword(password: string, djangoHash: string): boolean`
       - Splits djangoHash by '$'.
       - Checks the algorithm prefix:
         - If 'pbkdf2_sha256':
           - Extracts iterations, salt, and hash.
           - Runs crypto.pbkdf2Sync(password, salt, iterations, 32, 'sha256').
           - Converts calculated key to base64 string.
           - Compares calculated base64 with stored base64 using crypto.timingSafeEqual.
         - If 'md5':
           - Extracts salt and hash.
           - Calculates MD5 hash of (salt + password).
           - Compares calculated hex with stored hex using crypto.timingSafeEqual.
    2. `hashPassword(password: string): string`
       - Generates random 12-char salt.
       - Runs crypto.pbkdf2Sync with 600000 iterations, keylen 32, digest 'sha256'.
       - Returns format 'pbkdf2_sha256$600000$salt$base64hash'.
  </action>
  <verify>tsc --noEmit passes</verify>
  <acceptance_criteria>
    - lib/auth/django-password.ts contains verifyPassword and hashPassword functions.
    - Handles both pbkdf2_sha256 and md5 prefixes.
    - Uses crypto.timingSafeEqual for hash comparison.
  </acceptance_criteria>
  <done>Django password hashing utility created.</done>
</task>
