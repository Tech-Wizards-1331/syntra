# Phase 6 Plan — Team Registration, QR Code & Scanner UI

Rebuild the team formation, registration, and attendance checkout system in Next.js. Provide full-featured participant dashboards with QR codes, search-and-invite controls, and a camera scanner console with strict role authorizations.

## User Review Required

> [!IMPORTANT]
> - This phase relies on browser camera feeds (`html5-qrcode`). Local verification must happen under HTTPS or `localhost` to grant camera permissions.
> - Inviting a user or joining a team checks database constraints (e.g. email must not belong to another team for the same hackathon).

## Open Questions

None. The user has provided clear decisions regarding hybrid scanner routing, invite requests logic, and QR payload security.

## Proposed Changes

### [Server Actions]

Implement all team building mutations and scanner record processing.

#### [NEW] [teams.ts](file:///c:/Users/ansh/OneDrive/Desktop/Ansh/Sem-4/syntra/app/actions/teams.ts)
- Create `createTeam(hackathonId, teamName)`:
  - Verify participant role and profile completeness.
  - Generate random UUIDs for `qr_token` and `invite_token`.
  - Create the team, and atomically insert the leader as the first `TeamMember`.
- Create `joinTeam(inviteToken)`:
  - Look up team by `inviteToken`.
  - Validate registration deadline has not passed.
  - Block if user is already in a team (leader or member) for this hackathon.
  - Enforce team capacity bounds.
  - Atomically add user as `TeamMember` and clone skills from their profile.
  - Clean up all other pending requests for this user for this hackathon.
- Create `addGuestMember(teamId, data)`:
  - Verify leader ownership.
  - Insert guest record into `TeamMember` (without user login association).
  - Verify email is not already registered in this hackathon.
- Create `removeTeamMember(memberId)`:
  - Verify leader ownership or self-removal.
  - Remove member.
- Create `searchSoloParticipants(hackathonId, skillQuery)`:
  - Return users with `role = 'participant'`, incomplete profiles bypass, profile `visibility = true`, not already in a team, and matching skill criteria. Exclude the calling leader.
- Create `sendTeamRequest(teamId, receiverId)`:
  - Create `TeamRequest` with `status = 'pending'`.
- Create `acceptTeamRequest(requestId)`:
  - Set status to `accepted`, add member to team, clear other pending invites for user for this hackathon.
- Create `declineTeamRequest(requestId)`:
  - Set status to `declined`.

#### [NEW] [scans.ts](file:///c:/Users/ansh/OneDrive/Desktop/Ansh/Sem-4/syntra/app/actions/scans.ts)
- Create `scanQrToken(qrToken, scanCategoryId)`:
  - Check coordinator/organizer auth scopes.
  - Validate `team.is_qr_active`.
  - Return team name and member check-in states (true/false) for that category.
- Create `submitMemberScans(qrToken, scanCategoryId, memberIds)`:
  - Verify coordinator/organizer auth.
  - Validate all member IDs belong to team.
  - Atomically insert `ScanRecord` rows inside a transaction, blocking double scans.

### [UI Components]

Build participant dashboards and camera scanner views.

#### [MODIFY] [page.tsx](file:///c:/Users/ansh/OneDrive/Desktop/Ansh/Sem-4/syntra/app/participant/dashboard/page.tsx)
- Check if participant belongs to any team.
- **State A: Unregistered**:
  - Show list of active hackathons (in registration phase).
  - Show "Create Team" or "Join Team via Invite Token" forms.
  - Render "Received Invites" section listing pending `TeamRequest` items.
- **State B: Registered**:
  - Render Team Details Card (Name, invite token link, problem statement choice).
  - Render Team Members Table (showing leaders and guest records).
  - If Team Leader:
    - Show Guest Record creation form.
    - Show "Search & Recruit" search bar listing visible solo participants with an "Invite" button.
    - List sent invitations.
  - Render QR Code card using client-side dynamic wrapper for `qrcode.react` based on the team's secure `qr_token` UUID.

#### [NEW] [page.tsx](file:///c:/Users/ansh/OneDrive/Desktop/Ansh/Sem-4/syntra/app/organizer/scan/page.tsx)
- Server-side wrapper page. Check session role (must be organizer/coordinator).
- Extract `hackathonId` and `categoryId` from query parameters.
- If parameters are missing, render Hackathon and active Scan Category selectors.
- Once selected, load the client camera scanner interface.

#### [NEW] [ScannerClient.tsx](file:///c:/Users/ansh/OneDrive/Desktop/Ansh/Sem-4/syntra/app/organizer/scan/ScannerClient.tsx)
- Load camera scanning window using `html5-qrcode`.
- On barcode decode:
  - Retrieve member list via `scanQrToken`.
  - Render checkboxes for each member (disable already checked-in).
  - "Submit Scan" button calling `submitMemberScans`. On success, reset camera stream and show a success banner.
